<a name="introduction"></a>
## 简介

Dub 是面向[短链接](https://dub.co/home)、[转化跟踪](https://dub.co/analytics)和[联盟计划](https://dub.co/partners)的现代化开源链接归因平台。

我们的平台每月支撑超过 1 亿次点击和 200 万条链接，并被 Twilio、Buffer、Framer、Perplexity、Vercel、Laravel 等公司的一流营销团队所使用，[更多客户](https://dub.co/customers)参见此处。

### 常见的本地开发问题

- `The table <table-name> does not exist in the current database.` —— 运行 `pnpm prisma:push`，在不使用迁移文件的情况下，把 Prisma schema 文件的状态推送到数据库。
- 项目在本地未能正确构建 —— 请确认你的 `node` 和 `pnpm` 版本与上方推荐版本一致。删除 `apps` 和 `packages` 目录下所有的 `node_modules`、`.next` 和 `.turbo` 目录。现在你可以运行 `pnpm install` 重新安装 `node_modules`，并用 `pnpm build` 重新构建项目。

### 开发数据填充脚本

该脚本会用开发数据填充数据库，用于测试和开发目的。

**基本填充（添加数据但不删除现有数据）：**

```bash
cd apps/web
pnpm run script dev/seed
```

**填充前清空数据库（会先删除所有现有数据）：**

```bash
cd apps/web
pnpm run script dev/seed --truncate
```

使用 `--truncate` 时，脚本会在删除任何数据前请求确认。

## 许可证

Dub Technologies, Inc. 是一家商业开源公司，这意味着这个开源仓库的某些部分需要商业许可证。这一理念被称为 “Open Core”（开源内核）：核心技术（99%）完全开源，采用 [AGPLv3](https://opensource.org/license/agpl-v3) 许可证授权；最后 1% 则在一份商业许可证之下（["/ee" 企业版（Enterprise Edition）](<https://github.com/dubinc/dub/tree/ee/apps/web/app/(ee)>)），我们认为它完全契合那些需要企业级功能的大型组织。企业级功能由 Dub Technologies, Inc. 全职聘请的核心工程团队构建。
